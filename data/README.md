# data

- `land.json`: the land of [Natural Earth](https://www.naturalearthdata.com/)'s 1:50m outlines (`ne_50m_land`), public
  domain, simplified to about 1.5 km (Douglas–Peucker) and stored in hundredths of a degree, each ring with its box and
  its points as differences from the one before. The plugin crops it around the school's place to draw the locator map
  of «Tu centro» (`classes/local/place.php`); no map service is called.
